## ⚡ 极速开始 (Quick Start in 3 Seconds)

本项目采用**纯 Python 原生标准库实现，零第三方 pip 依赖，瞬时毫秒级冷启动**。

```bash
# 1. 运行自检
python main.py run

# 2. 自动化单元测试
python -m unittest discover tests
# 或
.\run.ps1 test

# 3. 探活检查
python main.py health
```

## ⚙️ 通用五大操作动词

```bash
powershell -File ./run.ps1 setup     # 环境检查
powershell -File ./run.ps1 test      # 全量单元测试
powershell -File ./run.ps1 health    # 毫秒级探活
powershell -File ./run.ps1 run       # 核心业务执行
powershell -File ./run.ps1 clean     # 缓存清理
```
